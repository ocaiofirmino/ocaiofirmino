# Ícones

Logos de HTML, CSS, JavaScript, Python, TypeScript, React, Tailwind CSS, VS Code, Git, GitHub, PowerShell, npm, Vite, Vercel, Excel, Linux, Power BI, PostgreSQL e Node.js: [Simple Icons](https://simpleicons.org/), distribuídas sob CC0. Os ícones de VS Code, PowerShell, Excel e Power BI usam a versão 11.15.0 do projeto. As marcas continuam pertencendo a seus respectivos titulares. O ícone de banco de dados de SQL e os demais elementos vetoriais foram desenhados para este perfil.
